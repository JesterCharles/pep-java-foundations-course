# PEP Java Foundations Course

This repository is a standalone copy of the complete Foundation course package from `pep-technology-content` at commit `1814ba7d884177bb941d1d5ebe038c132f3dcc03`.

## Directory map

- `modules/` - the 17 active Foundation teaching modules.
- `course-material/` - Foundation assessments, course reviews, and the preserved Git/Linux/AI course coding lab.
- `authoring/catalog/` - Foundation authoring catalogs.
- `authoring/evidence/` - Foundation review and evidence material.
- `SOURCE_MANIFEST.md` - source-to-destination mapping and scope.
