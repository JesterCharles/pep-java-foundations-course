# PEP Java Foundations Course

This repository is a standalone copy of the single `java-foundations/` course from `pep-technology-content` at commit `1814ba7d884177bb941d1d5ebe038c132f3dcc03`.
It contains no material from the other Foundation courses (Git/Linux/AI, SQL and JDBC, Collections and Streams).

## Directory map

- `modules/<module>/<topic>.md` - one lesson per topic, with `<topic>.html`, `<topic>.gift` and `<topic>.pdf` beside it where the source has them.
- `modules/<module>/<topic>/` - other files that belong to a topic (the `video-artifact.md` companions in `java-basics`).
- `modules/java-basics/coding-lab/` - the module coding lab: starter, tests and expected output.
- `course-material/java-foundations/assessments/` - the course assessment blueprint and question bank.
- `authoring/catalog/java-foundations/` - the authoring catalog for the course.
- `authoring/evidence/java-foundations/` - review and evidence records for the course.
- `SOURCE_MANIFEST.md` - source-to-destination mapping and every byte changed.
